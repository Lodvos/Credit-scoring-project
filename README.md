# Credit Scoring Project

## 📌 Описание проекта

Этот проект посвящён построению скоринговой модели для предсказания вероятности дефолта заемщика по заявочным данным. Курсовая выполнена на основе реальных данных платформы **Lending Club**. Реализованы как интерпретируемая модель (логистическая регрессия с WOE-преобразованиями), так и неинтерпретируемая модель машинного обучения с последующим сравнением качества и финансового эффекта.

## 🛠 Основные этапы работы

1. **Предобработка и анализ данных (EDA):**
   - Описание признаков
   - Работа с пропусками
   - Исследование распределений и целевого признака

2. **WOE-преобразование и построение скоринговой карты:**
   - Дискретизация признаков
   - Расчёт WOE и IV
   - Отбор переменных
   - Обучение логистической регрессии

3. **Альтернативная модель:**
   - Обучение ML-модели (например, Random Forest / XGBoost)
   - Валидация и сравнение моделей

4. **Финансовая оценка:**
   - Оптимизация порога отсечения
   - Расчёт ожидаемой прибыли от кредитования

## 📊 Используемые данные

- `tr_for_students.csv` — обучающая выборка  
- `vl_for_students.csv` — отложенная OOT-валидация  
- Описание полей: `columns_description.xlsx`

## 🧾 Стек технологий

- Python (Pandas, NumPy, scikit-learn, Matplotlib, Seaborn)
- WOE-преобразования (библиотека `scorecardpy` / кастомные реализации)
- Логистическая регрессия, ML-модели
- Git, Jupyter Notebook

## 📈 Результаты

- Интерпретируемая модель с высокой explainability  
- Альтернативная модель с повышенной точностью  
- Оптимизированный порог отсечения для максимизации прибыли  
- Подробный отчёт и презентация
